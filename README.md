# 🔩 재료기호 마스터 — SM45C · SS400 · GC250 해독

**기계제도 Ⅰ. 기계 제도에 의한 도면 그리기 — 9. 기계 재료 기호 표시** 단원용 학습·수업 보조 도구입니다.
설치 없이 브라우저에서 바로 실행되며, HTML 파일 하나로 오프라인·휴대폰에서도 작동합니다.

## 왜 만들었나

도면 부품란의 `SM45C`, `GC250`은 학생 눈에는 그냥 암호입니다. 통째로 외우면 금방 잊습니다.
이 도구는 기호를 **세 조각으로 끊어** 보여 주고(각 조각을 누르면 뜻이 나옴),
반대로 **재료 이름을 주고 조각을 끼워 기호를 만들게** 합니다.

가장 많이 틀리는 지점을 정면으로 다룹니다 — **끝 숫자의 뜻이 재료마다 다르다.**
`SM45C`의 45는 **탄소 0.45%**, `SC450`의 450은 **최저 인장 강도**, `SCP1`의 1은 **1종**입니다.

## 구성

| 모드 | 내용 |
|------|------|
| 📖 **배우기** (4쪽) | ① 부품란과 재료 기호 ② **기호 해독기**(조각을 눌러 뜻 확인, 재료 11종) ③ 첫·중간 부분 기호표 카드 뒤집기 ④ 끝에 덧붙는 기호(열처리·마무리) |
| **도전 ①** 기호 조립 | 재료 이름을 보고 **조각을 끼워 기호를 완성** (칸을 누르면 되돌리기) |
| **도전 ②** 기호 해독 | 기호 → 재료명 / 끝 숫자의 뜻 / 덧붙임 기호의 뜻 |
| **도전 ③** 부품란 읽기 | 교과서 **동력 전달 장치 부품란**에서 재질을 읽고 판단 |
| 🎯 **종합시험** | 조립 + 해독 + 부품란 + 구성 원리를 섞어 10문항 후 **결과 제출** |

## 기호의 구성 (KS · 교과서 표 Ⅰ-18 ~ Ⅰ-21)

```
S      M       45C
│      │        └ 끝 부분  : 종류 — 인장 강도 / 탄소 함유량 / 몇 종
│      └───────── 중간 부분 : 규격명·제품명 (주조품·단조품·판·관·공구강 …)
└──────────────── 첫 부분  : 재질 (S 강 · GC 회주철 · Al 알루미늄 …)
```

| 구분 | 자주 쓰는 기호 |
|------|----------------|
| 첫 부분(재질) | **S** 강 · **GC** 회주철 · **Al** 알루미늄 · Cu 구리 · Bs 황동 · Br 청동 · PB 인청동 · F 철 · WM 화이트메탈 |
| 중간 부분(규격·제품명) | **S** 일반 구조용 압연재 · **C** 주조품 · **F** 단조품 · P 판 · B 봉 · T 관 · W 선 · CP 냉간압연강판 · DC 다이캐스팅 · TC 탄소공구강 · KH 고속도공구강 |
| 끝에 덧붙임 | **A** 풀림 · **N** 불림 · **Q** 담금질·뜨임 · H 경질 · D 무광택 · B 광택 · K 킬드강 |

> **자리에 따라 뜻이 달라집니다** — `SS330`의 앞 S는 재질 ‘강’, 뒤 S는 제품명 ‘일반 구조용 압연재’.

수록 재료: SM45C · SC450 · SS330 · SS400 · SS540 · GC250 · ALDC6 · SCP1 · STC5 · SKH50 · SF440 · SCM440 · SCM415 · SPS7 · STB2 · STS2 · PBC2

## 수업에서 쓰는 법

- **수업 자료**: `배우기 ②`의 해독기에서 **SM45C → SC450** 순으로 보여 주며 "끝 숫자가 뭘 뜻하지?"를 물어보세요. 이 비교 하나가 이 단원의 핵심입니다.
- **형성평가(제출)**: 주소 뒤에 `?rc=<Apps Script URL>` 을 붙여 배포하면, 종합시험 종료 시 학생이 **반·번호**를 넣어 제출하고 결과가 구글 시트에 모입니다.
  ```
  .../material-symbol-master/?rc=https://script.google.com/macros/s/.../exec
  ```

> **선생님께 참고**: 일반 구조용 압연 강재는 교과서·기능사 관례대로 **최저 인장 강도 기준(SS330·SS400·SS540)** 으로 다뤘습니다.
> KS D 3503은 이후 항복 강도 기준 표기(SS275 등)로 개정되었으니, 필요하면 수업에서 한 줄 덧붙여 주세요.
